# M3 — Sistema visual, temas y fuentes

Objetivo: identidad visual minimalista y coherente, con temas que cubren UI y
terminal, fuentes configurables y todos los tamaños derivados de la fuente base.

## Criterio de hecho

- [x] Cambiar tema, fuente o tamaño base reescala y repinta sin reiniciar.
- [x] One Dark, Monokai y Cobalt2 aplican a UI y paleta ANSI.
- [x] Un tema de usuario en TOML se carga, valida y aplica en caliente.
- [x] Iconos Tabler tintados y marcas en color integrados.
- [x] Contraste AA y estados no basados solo en color.
