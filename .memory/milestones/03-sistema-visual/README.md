# M3 — Sistema visual, temas y fuentes

Objetivo: identidad visual minimalista y coherente, con temas que cubren UI y
terminal, fuentes configurables y todos los tamaños derivados de la fuente base.

## Criterio de hecho

- [ ] Cambiar tema, fuente o tamaño base reescala y repinta sin reiniciar.
- [ ] One Dark, Monokai y Cobalt2 aplican a UI y paleta ANSI.
- [ ] Un tema de usuario en TOML se carga, valida y aplica en caliente.
- [ ] Iconos Tabler tintados y marcas en color integrados.
- [ ] Contraste AA y estados no basados solo en color.
