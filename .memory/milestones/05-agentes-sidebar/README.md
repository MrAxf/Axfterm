# M5 — Agentes y sidebar

Objetivo: barra lateral de agentes agrupados por proyecto, con detección
automática del CLI en cada pestaña, estado fiable y salto directo a la terminal
que requiere atención.

## Criterio de hecho

- [ ] Sidebar con slots izquierdo/derecho y paneles movibles.
- [ ] Agentes agrupados por proyecto con estado visible.
- [ ] `opencode` y `copilot` detectados y atribuidos a su pestaña.
- [ ] Abrir pestaña de agente desde la sidebar y desde la paleta.
- [ ] Atención confirmada al enfocar; notificación visible.
- [ ] Escenarios con CLIs falsos pasan de forma determinista.
