# M6 — Teclado y command palette

Objetivo: operar todo el producto sin ratón, con atajos configurables por
contexto, sin robar teclas a la terminal, y una paleta que ejecute acciones y
salte a terminales, perfiles, proyectos y agentes, revelando proyectos en la
sidebar.

## Criterio de hecho

- [ ] Todo el flujo diario es operable solo con teclado, incluido abrir una
      terminal con cualquier perfil.
- [ ] `Ctrl+C` y demás teclas de terminal siguen llegando al PTY.
- [ ] Conflictos y teclas reservadas se detectan y explican.
- [ ] La paleta encuentra acciones, pestañas, perfiles, proyectos, agentes,
      temas y fuentes, y salta al agente que requiere atención.
- [ ] Existe una pantalla de atajos generada desde el registro de acciones.
