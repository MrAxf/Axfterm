# M2 — Layout, proyectos y pestañas

Objetivo: layout global con paneles divisibles y pestañas por panel, más los
proyectos como agrupación de pestañas en la sidebar; incluye overflow, drag &
drop y restauración de sesión.

## Criterio de hecho

- [x] 4 paneles y 20 pestañas repartidas en 3 proyectos de la sidebar sin
      glitches.
- [x] Un panel puede mezclar pestañas de proyectos distintos y el foco se
      conserva al mover pestañas.
- [x] La sidebar revela la pestaña enfocada; un click en una fila la enfoca.
- [x] Proyecto sin pestañas y workspace sin proyectos muestran estados
      accionables.
- [x] Splits redimensionables, foco claro y cierre que colapsa.
- [x] Pestañas reordenables y movibles entre paneles sin recrear el PTY.
- [x] Overflow usable con scroll, chevrons y menú de todas las pestañas.
- [x] Cerrar y reabrir la app restaura layout, proyectos (incluidos vacíos) y
      pestañas.
