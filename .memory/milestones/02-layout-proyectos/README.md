# M2 — Layout, proyectos y pestañas

Objetivo: workspace multi-proyecto con paneles divisibles y pestañas por panel,
incluido overflow, drag & drop y restauración de sesión.

## Criterio de hecho

- [ ] 4 paneles, 20 pestañas y 3 proyectos abiertos sin glitches.
- [ ] Splits redimensionables, foco claro y cierre que colapsa.
- [ ] Pestañas reordenables y movibles entre paneles sin recrear el PTY.
- [ ] Overflow usable con scroll, chevrons y menú de todas las pestañas.
- [ ] Cerrar y reabrir la app restaura layout, proyectos y pestañas.
